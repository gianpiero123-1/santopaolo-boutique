Anyone booking accommodation in Italy will notice a code on listings beginning with IT followed by a string of characters. This is the CIN, the national identification code.

## What it is for

It uniquely identifies every accommodation property and every short-let unit across the country. Each individual apartment has its own, distinct from the others even when they belong to the same operator.

The purpose is traceability: making it verifiable that a property offered to the public is registered and known to the authorities.

## Why it matters to guests

It is the fastest way to tell a properly registered operator from an improvised listing.

A property displaying a CIN is registered, has an identifiable owner and operates within a verifiable framework. A listing with no CIN, or with a code that does not match the address, is worth looking at more closely.

## Where to find it

It must appear on published listings, on booking platforms and on the property's own site. Many operators show it on the individual unit page or in the site footer.

If a property has several units, you should see several codes, one per unit.

<InPractice>
- Check the code refers to the specific unit you are booking
- A property with five apartments displays five distinct codes
- The CIN does not replace other checks, look at the VAT number and reviews too
- Ask for the code if it is not on the listing, a legitimate operator provides it without hesitation
</InPractice>
